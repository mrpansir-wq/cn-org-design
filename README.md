# cn-org-design

`cn-` 建设工程技能系列中的施工组织设计技能。用于依据正式施工图、勘察资料、合同、企业模板和项目要求，编制、修订、审查并交付房建工程施工组织设计。

## 系列技能

- [cn-high-formwork](https://github.com/mrpansir-wq/cn-high-formwork)：高大模板专项施工方案编制与审查

## 功能

- 建立项目事实矩阵并追溯资料来源
- 组织施工部署、流水顺序、进度与资源计划
- 编制主要分部分项工程施工方法及技术措施
- 审查章节、数据、规范、图文和项目适配一致性
- 创建并校验正式 DOCX 交付文件

## 安装

将仓库内的 `cn-org-design` 文件夹复制到 Codex 技能目录：

```text
~/.codex/skills/cn-org-design
```

重新启动 Codex 后，可通过 `$cn-org-design` 显式调用。

## 使用示例

```text
使用 $cn-org-design，根据正式施工图、项目资料和企业模板编制并验收施工组织设计。
```

## 说明

本技能辅助工程技术文件编制，不替代项目审批、专家论证、注册人员签章及现场责任主体的最终判断。项目事实、规范版本和关键安全参数必须由使用者复核。
