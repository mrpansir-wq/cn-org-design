# cn-org-design

面向中国房屋建筑工程的 Codex Skill，用于根据正式施工图、勘察报告、合同、企业模板和项目管理要求，编制、修订、审查并交付完整的施工组织设计。

它不是简单生成通用文本，而是按“资料清点 → 项目事实提取 → 施工部署 → 施工方法 → 管理策划 → 数据校核 → Word 排版 → 原生验收”的流程工作，尽量保证方案与目标项目匹配、工程数据可追溯、技术措施可实施、风险控制可闭环。

## 能实现什么

### 1. 从项目资料建立事实基础

- 递归清点施工图、勘察报告、合同、清单、进度计划、样文、企业制度和审查意见。
- 区分正式版、作废版和冲突版本，避免引用错误资料。
- 按单体和专业提取建筑面积、层数、高度、结构体系、基础形式、地质水文、材料等级和专业系统等信息。
- 建立“事实—来源—适用单体—章节去向—状态”矩阵，区分已核实事实、推导值、施工拟定值和待核实值。

### 2. 建立完整施工组织设计结构

- 根据企业目录建立十五章施工组织设计框架。
- 形成“章节—子章节—必写内容—图表—材料设备—资料来源”内容模型。
- 检查项目实际内容是否缺项，删除目标项目不存在的工艺和套用内容。
- 控制工程概况、施工部署、进度计划、资源计划和施工方法之间的章节归属，减少重复。

### 3. 编制施工部署和资源组织

- 编制项目组织机构、岗位职责、目标管理和总承包管理要求。
- 确定施工区段、施工顺序、流水组织、关键线路和专业穿插关系。
- 编制劳动力、材料、机械、周转料具、测量仪器和技术文件计划。
- 组织临建、临水、临电、道路、堆场、排水、消防及施工总平面管理。
- 输出可编辑的组织机构图、管理体系图、横道图等管理图表要求。

### 4. 编制分部分项工程施工方法

对项目实际存在的分部分项工程，按统一深度编制：

1. 适用范围与施工条件；
2. 材料及技术要求；
3. 人员、机械和仪器；
4. 工艺流程；
5. 施工方法；
6. 关键参数与拟定做法；
7. 质量标准和检查方法；
8. 安全、环保和消防控制；
9. 异常处置；
10. 成品保护。

参考模块覆盖测量放线、土方与深基坑、DDC 地基处理、钢筋模板混凝土、工业厂房、废水处理中心、防渗防腐、地下管廊、地下管网和机电安装等内容深度要求。

### 5. 编制项目管理策划

- 施工总平面布置与动态管理；
- 总进度、阶段进度、资源计划和保证措施；
- 检验试验计划和质量策划；
- 安全文明施工、环境保护、消防和应急管理；
- 季节性施工、科技创新及施工方案编制计划；
- 危大工程范围、监测、验收、停工条件和法定程序提示。

### 6. 审查和修订既有施工组织设计

- 核对图纸与正文、不同单体、不同章节、表格和图示之间的数据一致性。
- 识别他项目名称、错误参数、不适用工艺、套话、凑字数和同义重复。
- 检查材料、设备、参数、质量、安全、验收、异常处置和成品保护是否齐全。
- 识别“按图执行”“另详专项方案”“通过计算确定”等模糊甩项表述。
- 输出问题清单、修订建议或直接完成项目适配改版。

### 7. 创建并验收正式 Word 文件

- 设置封面、报审页、目录、标题、正文、图题、表题和表格样式。
- 创建可更新的 Word TOC 目录域。
- 控制表格宽度、重复表头、行不跨页、数字拆行和图示版心。
- 通过脚本审计 DOCX 的章节、样式、目录域、图片、表格和包结构。
- 要求使用 Microsoft Word 原生打开 QA 副本，更新域并检查关键页面。
- 对 Word 回存前后的媒体、表格和关系资源进行保护性比较。

## 适用场景

- 从项目施工图和基础资料新编施工组织设计；
- 将企业样文改编为目标项目正式版本；
- 按企业新版目录重构既有施工组织设计；
- 补全缺失章节、施工方法、资源计划或管理策划；
- 审查项目串词、数据矛盾、章节重复和规范适用性；
- 修复施工组织设计 DOCX 的目录、表格、图示和排版问题；
- 为工业厂房、群体工程、废水处理设施、地下管网等房建项目进行专项适配。

## 可接收的资料

- 建筑、结构、给排水、暖通、电气、消防等专业施工图；
- 岩土工程勘察报告、设计变更、图纸会审和技术核定资料；
- 合同、工程量清单、总进度计划、项目管理目标和企业制度；
- 企业施工组织设计目录、Word 模板、历史样文和审查意见；
- 项目组织机构、人员、机械、材料、临建和现场条件资料。

资料可以是 DOCX、PDF、CAD、图片或表格。处理具体格式时，技能会根据任务调用相应的 Word、PDF、CAD 或表格能力。

## 工作流程

1. 建立资料清单与版本边界；
2. 深读图纸并建立项目事实矩阵；
3. 建立目录和章节内容模型；
4. 编制施工部署与资源组织；
5. 编制主要施工方案及技术措施；
6. 编制管理策划和各类计划；
7. 执行数据、内容和项目适配校核；
8. 创建 Word 并完成原生排版；
9. 执行 DOCX 审计与 Microsoft Word 双重验收。

## 输出成果

根据用户要求可输出：

- 完整施工组织设计 DOCX；
- 正式章节或补充章节；
- 施工组织设计审查意见表；
- 项目事实矩阵和待核资料清单；
- 问题清单、风险清单和修订版文件；
- DOCX 结构审计结果。

正式定稿前，如果重大数据冲突、正式图纸缺失或危大工程关键参数无法可靠确定，技能会停止宣称文件已具备正式交付条件，并输出最小待补资料清单。

### 目录内容说明

| 文件 | 内容与作用 |
| --- | --- |
| `SKILL.md` | 技能主流程。规定资料优先级、项目事实矩阵、施工部署、施工方法、管理策划、数据校核、Word 创建及交付停止条件。 |
| `agents/openai.yaml` | Codex 技能列表中的显示名称、简介和默认调用提示。 |
| `references/enterprise-outline-and-format.md` | 企业十五章目录、标题层级、封面、正文、图表格式及章节归属规则。 |
| `references/content-depth-and-project-adaptation.md` | 项目适配原则、施工方法最小深度、关键专业编制深度、参数和材料规则。 |
| `references/content-review-checklist.md` | 事实数据、章节完整性、禁止性表述、重复内容、风险和法定程序审查清单。 |
| `references/word-delivery-and-qa.md` | Word 样式、表格、图示、目录域、原生 Word 检查和 OOXML 包结构保护规则。 |
| `scripts/audit_docx.py` | 对施工组织设计 DOCX 执行结构化审计，可输出文本或 JSON 结果。 |

## 安装

```bash
git clone https://github.com/mrpansir-wq/cn-org-design.git
cp -R cn-org-design/cn-org-design ~/.codex/skills/cn-org-design
```

重新启动 Codex 后，通过 `$cn-org-design` 显式调用。

## 调用示例

```text
使用 $cn-org-design，读取项目施工图、勘察报告和企业模板，编制完整施工组织设计并交付 DOCX。
```

```text
使用 $cn-org-design，审查现有施工组织设计，重点检查项目串词、章节缺项、数据矛盾、施工方法深度和 Word 排版。
```

```text
使用 $cn-org-design，按企业十五章目录重构这份施工组织设计，保留项目有效内容并删除不适用工艺。
```

## 审计脚本

```bash
python cn-org-design/scripts/audit_docx.py /absolute/path/to/document.docx
```

输出 JSON：

```bash
python cn-org-design/scripts/audit_docx.py /absolute/path/to/document.docx --json
```

## 系列技能

- [cn-high-formwork](https://github.com/mrpansir-wq/cn-high-formwork)：高大模板专项施工方案编制、计算书联动和专家论证深度审查。

## 使用边界

本技能辅助工程技术文件编制，不替代项目法定审批、专家论证、注册人员签章、设计确认和现场责任主体的最终判断。项目事实、规范版本、施工参数和安全控制条件必须由使用者结合受控资料复核。
