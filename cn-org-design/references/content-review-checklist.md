# 内容审查清单

## 目录

1. 事实与数据
2. 完整性
3. 禁止性表述
4. 重复与凑字数
5. 风险和程序

## 1. 事实与数据

- 工程名称、位置、建设单位、范围与合同一致。
- 建筑面积、层数、高度、结构、基础、地基处理和抗震数据有来源。
- 混凝土、抗渗、钢筋、砌体、防水、防腐和节能参数按单体或构件核对。
- 危大工程范围与基坑深度、模板高度、跨度、吊装重量等实际参数一致。
- 进度、资源和临建计算使用同一高峰人数与工期基准。
- 正文、表格、组织图、横道图和附表数据互相一致。

## 2. 完整性

- 十五章齐全，章名正确。
- 工程概况八类内容齐全。
- 施工部署包含组织机构、目标、总包管理、资源供应和流水流程。
- 第五章只包含项目实际存在的施工方法。
- 材料出现处有材料技术要求。
- 深基坑、DDC、结构、围护、装饰、屋面、防水、防渗防腐、管廊、室外和机电均达到同等逻辑深度。
- 有总进度安排和横道图。
- 有临时设施、资源、检测装置和技术文件配置表。
- 有检验试验、质量、安全、环境、季节性、科技创新和方案编制计划。

## 3. 禁止性表述

在成熟施工方法中查找并重写：

- “按图施工”“按图纸执行”；
- “另详专项方案”“详见专项方案”；
- “通过专项方案计算确定”；
- “各单体另有要求时按对应单体执行”；
- “以受控图纸为准”作为缺失参数的替代；
- “正式实施参数以……为准”反复出现；
- “本章按……组织”之类只解释写作结构、不提供施工内容的元话语；
- “原则性编制”“可支撑原则性编制”等交付说明；
- “深化”作为不明确的标题；
- 仅列“停检点、旁站与复工”或“交底、记录和验收资料”的空泛小节。

允许在编制依据、法定程序或版本管理处说明受控文件和专项方案要求，但不得用其逃避本施组应给出的总体做法。

## 4. 重复与凑字数

- 删除连续重复段落、完全重复表格和换词重复。
- “施工方法”与“分步作业与记录”只保留前者并合并独有信息。
- 同一材料验收要求在首次完整说明，后续引用具体条款，不整段复制。
- 同一安全通用要求放在职业安全章；施工方法只保留该工艺特有风险。
- 同一质量通用要求放在质量章；施工方法只保留控制参数和检查点。
- 每段应回答项目事实、施工动作、控制参数、责任或检查方式中的至少一项；纯口号删除。
- 页数不是目标。正常深度来自项目范围和可执行细节，不得复制扩写凑到预设页数。

## 5. 风险和程序

- 危大工程列出部位、规模、主要风险、拟定措施、监测、验收、停工条件和法定程序。
- 风险与措施一一对应，使用风险控制表，不裸列风险名称。
- 结构安全、深基坑、起重吊装、高支模、脚手架、临电和有限空间等关键内容明确责任与检查。
- 未完成专家论证或审批不得写成已经完成。
- 不虚构计算书、检测结果、现场验收、签字、盖章或审批记录。
