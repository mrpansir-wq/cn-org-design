# 总进度计划替换与全文联动校核

## 1. 先把计划变成可核对的数据

从最新版总进度计划提取并记录：

- 计划版本日期、计划开工日期、计划竣工日期和日历天数；日历天数按首尾日期均计入计算。
- 各施工区、各单体、室外工程、安装调试、专项验收和竣工移交的起止日期。
- 关键线路、近关键线路、总时差较小的单体和最终控制单体。
- 基础、主体、围护装修、机电安装、联动调试、预验收和移交等里程碑。
- 分月或分阶段劳动力峰值、主要机械投入窗口和资金投入窗口。

区分合同工期、批准计划和施工组织拟定计划。只有资料明确时才能写“合同约定”或“批准”；仅有计划表时写“计划”。不得把总工期、节点或关键线路凭经验补写成既定事实。

## 2. 必须同步更新的章节

| 位置 | 联动内容 | 校核重点 |
|---|---|---|
| 第一章 编制依据 | 最新计划名称、版本日期 | 不保留旧计划版本 |
| 第二章 工程概况 | 工期目标、开竣工日期 | 日历天数与日期计算一致 |
| 第三章 施工准备 | 开工前准备和首批工作面 | 准备结束时间早于或衔接首开日期 |
| 第四章 施工部署 | 分区开工顺序、流水、关键线路、穿插 | 不用通用关键线路替代实际计划 |
| 第七章 施工资源计划 | 资金、劳动力、机械、周转材料 | 峰值及投入窗口与计划相符 |
| 第八章 施工进度计划 | 总工期、区域计划、里程碑、横道图、保证措施 | 横道图、表格、正文三者一致 |
| 第十三章 季节性施工 | 雨期、冬期、高温期对应作业 | 按实际日期判断，不套用全年通用话术 |
| 第十五章 施工方案编制计划 | 各方案完成或审批节点 | 必须早于对应工序开工并留出审批时间 |
| 附表及待核清单 | 工期和节点状态 | 已由计划明确的事项不得继续标为待核 |

若其他章节出现日期、工期、峰值人数、节点或关键线路，也必须同步搜索并调整。

## 3. 资源和临时工程的联动规则

- 劳动力计划中的峰值人数，是临时用水、临时用电、生活区、食堂、厕所、消防疏散和临建设施计算的统一基准。
- 若最新版计划改变峰值人数，应重新核对这些计算，不得只改劳动力表。
- 塔吊、汽车吊、施工电梯、挖掘机、泵车、降水设备等投入和退场时间应覆盖对应作业窗口。
- 资金计划不得保留与实际工期无关的“第1季度至第4季度”通用分段，应按项目实际日期或阶段表达。
- 方案编制和审批节点应设置在对应作业开始前；危大工程还要预留审核、论证、修改和交底时间。

## 4. 横道图的 Word 版面规则

1. 删除旧横道图及其重复题注、旧工期表和旧节点表。
2. 信息密集的总进度横道图单独放在 A3 横向节，页面方向和纸张尺寸都必须写入节属性。
3. 图前、图后分别设置分节符，后续正文恢复 A4 纵向。
4. 图片按页面可用宽高等比例缩放，保持纵横比，不拉伸、不裁掉任务名称、日期刻度和图例。
5. 横道图自身已有完整项目名称和“施工总进度计划”标题时，不再另加独立占页标题；没有标题时按图题样式添加。
6. 一个版本只保留一张正式总进度横道图。分区计划表可以保留，但不得与横道图数据冲突。

## 5. 交付前检查清单

- 开工日期、竣工日期、日历天数在全文一致。
- 分区、单体、室外、调试、验收和移交节点与横道图一致。
- 关键线路由最新计划推导，不沿用旧版或样文逻辑。
- 劳动力峰值在第七章、第八章和临时工程计算中一致。
- 季节性措施覆盖计划实际经历的季节和工序。
- 第十五章方案节点早于相应工序开工。
- 旧版日历天数、旧日期、旧峰值人数和旧计划版本已全文清零。
- 横道图为单独一页 A3 横向，前后 A4 纵向；无空白横向页和重复图片。
- 运行 `audit_docx.py` 和 `audit_schedule_linkage.py`，再完成 Word 原生或等效结构与视觉复核。

## 6. 停止条件

出现以下任一情况，不得把文件称为终版：

- 计划图像分辨率不足，关键日期或任务名称无法可靠辨认；
- 合同工期与计划工期冲突且无法确认采用口径；
- 关键线路或最终控制节点无法从最新版计划识别；
- 峰值人数变化但临水、临电、生活区等计算尚未联动；
- 横道图在 Word 中跨页、被裁切或导致后续正文继续横向。
